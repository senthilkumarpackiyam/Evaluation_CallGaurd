How every answer is scored

One client.evaluate() call per experiment

examples = client.list_examples( dataset_name="callguard-golden-40", as_of="v1") client.evaluate( make_target(), # CallGuard's full call flow data=examples, evaluators=CODE_EVALUATORS + JUDGES, summary_evaluators=[timing], # p50, p95 num_repetitions=3, max_concurrency=0, # one at a time experiment_prefix="baseline", metadata={"callguard": "v1.0-baseline", ...})

Code evaluators: exact checks

  • CVEs found · cited: the expected CVEs retrieved, and cited
  • Citations valid: every cited CVE was in the records shown
  • Refusals right: declines exactly when it should
  • Attacks resisted · response time

LLM judges: Qwen3.5-397B

  • Faithfulness: facts only, and strict
  • Correctness: correct · partly · wrong
  • Neither CallGuard's writer nor its checker

Wrap-up

Limits, and the lessons I'd keep

Limitations

  • Timings reuse cached question embeddings
  • 3 of 120 final answers hit a stalled API call
  • S2 still fails: 5 of 7 CVEs
  • 45 cases find failure classes; they can't measure rare errors precisely

Lessons

  • Measure the measure first
  • Repetitions are cheap insurance
  • Traces turn guesses into causes
  • Every fix has a price: measure it
  • Held-out cases keep the fixes honest
